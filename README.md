# Chatik

Простой self-hosted веб-мессенджер: комнаты, сообщения в реальном времени и история в SQLite. Никаких внешних сервисов или платных API.

## Требования

- Node.js 18 или новее
- npm

## Запуск

```bash
npm install
npm start
```

По умолчанию приложение доступно на `http://localhost:3000`.

Порт можно изменить через переменную окружения `PORT`:

```bash
PORT=8080 npm start
```

В Windows PowerShell:

```powershell
$env:PORT=8080; npm start
```

## Деплой на Render

Войдите в Render, подключите GitHub и создайте Blueprint из репозитория `decryptonator/chatik`: Render использует `render.yaml` в корне репозитория. Выберите бесплатный Web Service, если Render предложит план. После деплоя откройте адрес сервиса с суффиксом `onrender.com`.

На бесплатном тарифе Render не поддерживает постоянные диски: SQLite-файл на локальной файловой системе может исчезнуть при перезапуске, простое с выключением сервиса или новом деплое. Для чата задан `DB_FILE=/tmp/chatik.sqlite`; история сообщений на бесплатном тарифе не гарантированно сохраняется. Для постоянной истории нужен платный тариф с диском либо переход на внешнюю базу данных.

Дополнительные переменные окружения:

- `HOST` задаёт адрес прослушивания. По умолчанию `0.0.0.0`, поэтому приложение доступно в локальной сети и на хостинге.
- `DB_FILE` задаёт путь к файлу SQLite. По умолчанию рядом с `server.js` создаётся `chatik.sqlite`.

## Возможности

- вход по нику, ник сохраняется в браузере;
- создание и выбор комнат;
- доставка сообщений в реальном времени через WebSocket;
- история последних 100 сообщений каждой комнаты хранится в SQLite;
- тёмная адаптивная тема.

Чтобы открыть чат друзьям, разверните приложение на своём сервере или хостинге с Node.js и убедитесь, что выбранный порт доступен. Файл базы данных должен находиться на постоянном диске хостинга.
